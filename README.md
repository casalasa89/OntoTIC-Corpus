# Corpus OntoTIC

Repositorio para los metadatos del corpus

El conjunto de datos principal contiene **9.375 registros** y el subconjunto LDA estricto contiene **8.418 documentos modelables** en el periodo de estudio **2010–2026**. La versión del repositorio excluye el texto completo redistribuido y conserva los identificadores de documentos, los actores, los años, los tipos de fuente, las fuentes, el DOI, las decisiones de validación y la elegibilidad para LDA. El archivo de investigación controlado conserva la URL extendida y la auditoría de hash.

## Archivos disponibles



- `docs/DATA_DICTIONARY.md`: descripción de campos.
- `interfaz_ontotic/`: código de la interfaz local; sus datos de ejecución se distribuyen por separado.

**Alcance de esta entrega:** la descripción del estudio se refiere al periodo 2010–2026, pero el archivo de metadatos actualmente descargable en este repositorio lleva el corte 2010–2022. No debe interpretarse ese archivo como una descarga completa del corpus 2010–2026 hasta que sea sustituido y verificado.
